## Root Cause

The feature builder PR (#62) bumped the version in `package.json` but the tag push is a post-merge manual step. Neither the merge CI nor the feature builder skill pushes the tag automatically.

## Prevention

The TOOLS.md release process says: "Tag (`git tag vX.Y.Z`) and push tag after merge; auto-publishes to npm via OIDC." The daily feature builder should check for this gap before looking for new work.
